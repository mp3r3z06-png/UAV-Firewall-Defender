# UAV-Firewall-Defender
Packet-filtering script in C or Bash to block malicious network traffic aimed at a simulated drone's control system, mirroring real-world cyber mission rehearsal exercises.
I will protect a drone's ground control station from a cyberattack. I will start by deploying a vulnerable C-based socket listener, simulate a denial-of-service/command injection attack, and then build a two-layer defense system using network firewalls (iptables) and application-layer payload inspection (C).
